AWS Config is a monitoring and compliance[Following required rules, standards, laws, or security policies.] service that records AWS resource configurations, tracks configuration changes, and evaluates resources against compliance rules.

## Why AWS Config Is Used

AWS Config helps answer questions like:

- Who changed the security group?
- When was the EC2 instance modified?
- Is S3 bucket encryption enabled?
- Are resources compliant with company policies?
- What was the previous configuration?

## How AWS Config Works

```bash
AWS Resource Created/Modified
            ↓
AWS Config Records Configuration
            ↓
Stores Configuration History
            ↓
Evaluates Config Rules
            ↓
Marks Resource as:
COMPLIANT or NON_COMPLIANT
```

## Example

Suppose a developer changes:

Security Group port from 22 → 0.0.0.0/0

AWS Config:

- detects the change,
- records old & new configuration,
- evaluates compliance rule,
- marks it NON_COMPLIANT,
- optionally sends notification.

## Steps to work with AWS Config

### Create a custom Lambda rule to check if the EC2 instance is using the latest AMI.

### Steps to create aws config rule using custom Lambda function.
1. Create a new Lambda function.
2. Runtime: Python 3.12.
3. Give the permission to the Lambda function to access the EC2 instance.
 - AmazonEC2FullAccess (To access the EC2 instance)
 - AWS_ConfigRole (To access the AWS Config)
 - AWSCloudTrail_FullAccess (To access the CloudTrail)
 - CloudWatchFullAccess (To access the CloudWatch)
4. Write a code to check if the EC2 has monitoring option enabled.

```python 
import boto3
import json

def lambda_handler(event, context):

    # Get the specific EC2 instance.
    ec2_client = boto3.client('ec2')
    
    # Assume compliant by default
    compliance_status = "COMPLIANT"  
    
    # Extract the configuration item from the invokingEvent
    config = json.loads(event['invokingEvent'])
    
    configuration_item = config["configurationItem"]
    
    # Extract the instanceId
    instance_id = configuration_item['configuration']['instanceId']
    
    # Get complete Instance details
    instance = ec2_client.describe_instances(InstanceIds=[instance_id])['Reservations'][0]['Instances'][0]
    
    # Check if the specific EC2 instance has Cloud Trail logging enabled.
    
    if not instance['Monitoring']['State'] == "enabled":
        compliance_status = "NON_COMPLIANT"

    evaluation = {
        'ComplianceResourceType': 'AWS::EC2::Instance',
        'ComplianceResourceId': instance_id,
        'ComplianceType': compliance_status,
        'Annotation': 'Detailed monitoring is not enabled.',
        'OrderingTimestamp': config['notificationCreationTime']
    }
    
    config_client = boto3.client('config')
    
    response = config_client.put_evaluations(
        Evaluations=[evaluation],
        ResultToken=event['resultToken']
    )  
    
    return response
```

```bash
This Lambda function is triggered by AWS Config whenever an EC2 instance configuration changes.
It checks whether detailed monitoring is enabled on the EC2 instance.
If monitoring is enabled, the instance is marked as COMPLIANT; otherwise NON_COMPLIANT.
```

1. Go to AWS Config Console.
2. Click on Rules and add a new rule.
3. Select the rule type as `Create custon Lambda rule`.
4. Give a name to the rule.
5. Provide the lambda function ARN.
6. Trigger type: When Configuration changes.
    - Click on respource type: EC2 instance.
7. Save
